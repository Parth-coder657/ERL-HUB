# Optional genuine screenshots

included. If your instructor requires screenshots, capture them from a real
local run of ERL-HUB and save only genuine captures here. Useful screens are:

1. The inventory and fictional seed supplies.
2. The request queue showing urgent medical priority.
3. A successful dispatch and its manifest.
4. The save/load confirmation and audit history.

Keep personal information and real emergency/incident data out of screenshots.
